Why every app on your computer is secretly a web page

By Dana Okafor · 6 min read · Updated 2h ago

Open the chat app, the music player, the code editor and the note-taking app on a typical laptop and you are, in a very literal sense, running four copies of a web browser. Electron, the framework behind most of them, bundles Chromium and Node.js into a single package so that teams can ship one codebase to Mac, Windows and Linux.

That convenience has a side effect few users think about: everything you see in those apps is HTML, CSS and JavaScript, the same stuff as any website. And anything that is a web page can be inspected, styled and modified while it runs.

Enthusiasts have exploited this for years. Theming tools restyle music players, client mods add features to chat apps, and userscript managers let people rewrite websites with a few lines of code. The barrier has always been that someone has to write that code.

A new wave of tools aims to remove that barrier by having a language model write the modification from a plain-English request, running locally so nothing leaves the machine.

Whether app makers embrace or resist that shift remains to be seen. Some apps already lock down debugging ports; others publish official extension APIs. What is clear is that the line between using software and shaping it is getting thinner.
