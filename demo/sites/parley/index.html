What's the difference between debounce and throttle?

Both limit how often a function runs, but they answer different questions:

  1. Debounce waits until calls stop for n ms, then runs once. Good for search-as-you-type.
  2. Throttle runs at most once every n ms while calls keep coming. Good for scroll and resize handlers.

Rule of thumb: debounce when you only care about the final value, throttle when you need steady updates.

Show me a tiny debounce implementation

Here's the whole thing: keep a timer, reset it on every call, and only fire when it survives:

const debounce = (fn, ms) => { let t; return (...a) => { clearTimeout(t); t = setTimeout(() => fn(...a), ms); }; };
