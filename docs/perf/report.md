# Morse performance report

Generated by `node demo/perf.js` on 2026-10-24 (3 runs per cell, medians). Cells read `before → **after**`; the baseline is `docs/perf/before.json` (2026-10-24).

Measured in headless Chromium through the real desktop connector (CDP, main world, so every call Morse makes is counted by wrapping the page's built-ins and attributing calls by stack) and, for the last table, through the real unpacked extension. Deltas are against the same page without Morse.
