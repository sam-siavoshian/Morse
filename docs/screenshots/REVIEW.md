# Screenshot review

Every picture the docs, the website and the store kit use, the script that
makes it, and whether it passed a look on October 24, 2026. A picture passes
(✅) when it uses today's words (Save, Change, Edit tools, no local models),
nothing is cut off, the bar doesn't cover what the picture is about, nothing
looks broken, and it shows the gray Morse design. ⚠️ means it is still out of
date, with why.

How to retake them: [Testing → Screenshots](../dev/testing.md#screenshots).
