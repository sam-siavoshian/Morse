    Install

    One app. Nothing else to set up.

    Download Morse and open it. It finds Claude Code or Codex by itself and lists your apps and browsers.

    The Morse app

    For your apps and websites

    1. Download Morse and open it.
    2. Click Open with Morse next to an app.
    3. Press Ctrl+Shift+Space in the app (⌥Space on a Mac), point at something and say what you want.

    Downloads for every computer
    1. Mac with Apple silicon · Mac with Intel · Windows · Linux
    2. On a Mac, no security prompts: paste curl -fsSL https://raw.githubusercontent.com/sam-siavoshian/RRAA/main/install-app.sh | sh in Terminal. It checks Morse, puts it in Applications and opens it.
    3. Downloaded in a browser, Morse isn't signed yet, so the first time: on a Mac, open Morse, then System Settings, Privacy & Security, Open Anyway. On Windows, More info, then Run anyway.
    4. No model yet? Morse says what to get, or takes an API key.

    Your first minute

    1. 1Open Morse. Its name forms out of dots, then Begin. It finds your AI and your apps by itself.

    2. 2Click Open with Morse. Point at something, describe a change and click Save.

    3. 3Three moves in any app or browser: the shortcut, point, say it.

    Privacy

    Morse has no account and no server. When you ask for a change, Morse sends what you pointed at and what you said to your model. Nothing goes to the people who make Morse. Read the privacy policy

    FAQ

    Common questions.

    More in the guides.

    What do I install?

    One app: Morse. Download it, open it, and it finds your model, your apps and your browsers. There is nothing else to install.

    Do I need a terminal or Node?

    No. The Morse app has everything in it. There is also a morse command for developers, in the developer guide.

    What does it cost?

    Morse is free. Your model costs what it costs you now. Claude Code and Codex use your plan. With an API key, Anthropic or OpenAI bills you for each request. A change is usually one request.

    Which models can I use?

    Claude Code or Codex, if you have them. Or an Anthropic or OpenAI API key. Or a model on your own computer, such as LM Studio or llama.cpp. So far, only Claude Code was tested on real apps.

    Which apps work?

    Websites in your browser — Chrome, Edge, Brave, Arc or Vivaldi — and desktop apps built from web pages. Tested on Visual Studio Code, VSCodium, Obsidian, Logseq and Joplin, on Linux. Not tested yet: Slack, Discord, Spotify, macOS and Windows. Apps like Finder or Word aren’t built from web pages, so they don’t work.

    Do I need to know how to code?

    No. You describe the change in your own words. If you can code, you can read and edit every line Morse writes.

    What if the app or site updates?

    Morse never changes the app’s files, so updates install as usual. If an update breaks a mod, click Fix it in the Mods panel. Your model writes a new version.

    Is it safe to install mods other people made?

    A mod is code that runs in that site or app. Before you install one, Morse tells you what it does and shows its code. One shortcut turns off every mod on a page.
