Change any app
in your own words.

Morse lets you change any website or desktop app just by saying what you want, so the apps you use every day work the way you like.

Get it for Chrome Get it for desktop apps

Uses Claude Code, Codex or your own API key. No account.

How it works

Point. Say it. Watch it change.

  1. ⌥Space
    01

    Point at anything

    Press ⌥ Space in any page or app and click a button, a sidebar or a feed. Or skip pointing and describe a change to the whole page.

  2. “hide Shorts”
    02

    Say what you want

    One sentence. Restyle it, hide it, or add something that wasn’t there: a word count, a sleep timer, a focus mode.

  3. 03

    Watch it change

    The new look shows up while the model is still writing. If the change doesn’t work, Morse shows the model what went wrong and it fixes it. Save it to keep it, or undo it.

Voice

Hold the shortcut and talk.

Tap ⌥ Space to type. Hold it to speak. Let go, and Morse starts on the change.

  • In Chrome, the browser turns your speech into text.
  • In desktop apps, Morse uses your OpenAI key or Whisper on your computer.
  • Shortcuts are yours to change. Morse refuses the ones that would quit your app.

Models

Bring your own model.

Morse has no server and no account. It sends what you pointed at and what you said to the AI you already use, and shows you the change it writes.

  • Claude Code Uses your existing Claude Code sign-in.
  • Codex Uses your existing Codex sign-in.
  • An API key From Anthropic or OpenAI.

Where it works

Websites and desktop apps.

Most apps you use every day are built from web pages. Morse adds one small layer inside them, in the browser or in the app.

Any website

A Chrome extension. With “Allow User Scripts” on, mods that add buttons or features run on every site, even ones with strict security settings.

Privacy

        
Your mods stay on your computer.

        
There is no Morse account and no Morse server. Nothing you make is uploaded unless you share it. The privacy policy lists everything that leaves your computer.

      

      

        

          
Kept on your computer

          
Desktop mods live in ~/.morse/mods. Website mods live in the extension’s own storage.

        

        

          
Links carry the mod

          
A share link holds the whole mod after the #. Browsers never send that part to a server.

        

        

          
You see the code

          
Every change shows its code, can be undone, and never happens without you seeing it. Before you install a shared mod, Morse says what it does and shows every line.

        

        

          
You pick the model

          
Your request, the page address and what you pointed at go to the model you chose, only when you send a request.

        

      

    

  


  
  

    

      

        
FAQ

        
Questions people ask.

      

      

        

          What leaves my computer?
          
When you ask for a change, Morse sends your request, the page address and title, and the part of the page you pointed at to the model you chose. When you open Morse, it may download the gallery list from GitHub, at most once a day. Nothing goes to the people who make Morse. Read the privacy policy.

        

        

          Which models can I use?
          
Claude Code or Codex, if you have them. Or an Anthropic or OpenAI API key. Or any server that works like OpenAI's, including one on your own computer, such as LM Studio or llama.cpp. morse setup finds what you have.

        

        

          What does it cost?
          
Morse is free. Your model costs what it already costs you: Claude Code and Codex use your subscription, and with an API key, Anthropic or OpenAI bills you for each request. A change is usually one request, and one more if Morse has to fix it.

        

        

          Which apps work?
          
Any website in Chrome. Desktop apps built from web pages, like Spotify, Slack, Discord, VS Code, Notion and Obsidian. A few apps block the connection Morse needs; morse fuses <app> tells you before you try. Apps that are not built from web pages, like Finder or Word, don’t work.

        

        

          Do I need to know how to code?
          
No. You describe the change in your own words. If you do code, you can read and edit every line Morse writes.

        

        

          What if the app or site updates?
          
Morse never changes the app’s files, so updates install as usual. If an update moves things around, a mod can stop working. Fix it in the Mods panel asks your model to repair it.

        

        

          Is it safe to install mods other people made?
          
A mod is code that runs in that site or app. Before you install one, Morse tells you in plain words what it does and shows its code. Someone reads every gallery mod before it goes in. One shortcut turns off every mod on a page.

        

      

    

  


  
  

    

      

        
Install

        
Set up in about a minute.

        
You need Node 22 or newer, and Claude Code, Codex or an API key.

      

      

        

          
Desktop apps

          

            
$ npm install -g morse-cli
$ morse setup

            
          

          
morse setup finds Claude Code, Codex or an API key and asks which to use. Then open an app with Morse:

          

            
$ morse launch spotify

            
          

          
Also slack, discord, vscode, notion, obsidian, or a path to the app.

        

        

          
Chrome

          
    
            
  1. Install the morse command as above. The extension comes with it: morse extension shows its folder.
    2. 
            
  2. Open chrome://extensions, turn on Developer mode, click Load unpacked and choose that folder.
    3. 
            
  3. In Morse’s details, turn on Allow User Scripts.
    4. 
            
  4. Run morse serve and type its code into Morse. Or paste an Anthropic API key in Morse’s settings instead.
    5. 
          

          
Then press ⌥ Space on any page (Ctrl Shift Space on Windows and Linux). Morse is coming to the Chrome Web Store.

        

      

      
Morse is early: the status notes say exactly what has been tested.
