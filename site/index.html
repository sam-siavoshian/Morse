How it works

Point at it. Say it. Watch it change.

No settings to learn and no code to write. Say what you want, the way you’d tell a friend.

  1. 01

    Press the shortcut and point

    Press ⌥ Space in any page or app (Ctrl Shift Space on Windows and Linux), then click a button, a sidebar or a feed. Or skip pointing and describe the whole page.

  2. 02

    Say the change

    One sentence. Type it, or hold the shortcut and talk. Restyle it, hide it, or add something that wasn’t there: a word count, a sleep timer, a focus mode.

  3. 03

    Watch it, then save it

    Your model writes the change and you see it right away. Save keeps it as a mod: a change you saved. Morse brings it back every time you open that site or app.

Ideas to ask for: “hide Shorts everywhere” · “add a sleep timer that pauses the music” · “show a live word count under the message box” · “use the full width for pull request diffs”

Ideas, with an example mod for each in the gallery.

  • Hide what’s in the way

    Shorts on YouTube, trends on X, upsells in Discord.

  • Add what’s missing

    A sleep timer in Spotify, a word count in ChatGPT.

  • Make it easier to read

    Dark mode for Hacker News, a comfortable reading pane in Gmail.

  • Give it more room

    Full-width pull request diffs on GitHub.

  • Help you focus

    Fade the channels with nothing new in Slack, a focus mode for Notion.

  • Or edit it by hand

    Point at something and the Edit tools appear: hide, move, resize, edit text, recolor. No model, no waiting.

The gallery’s mods were written by hand for each site and app, not each tried on the live site. Sites change, so one may need a fix.

Show me once

Do it once. Morse does it from then on.

Clicking the same things over and over? Do the task by hand once and Morse writes down each step. Then say what to do with them: a button, a shortcut, or the same steps for every unread email.

  • Each step in plain words as you go: Click “Archive”.
  • Passwords and card numbers show as “(hidden)” and are never kept.
  • Save it, change it or undo it, like any change.

Fixes itself

When a site changes, your mods catch up.

Sites move things around. When a mod stops working, the Mods panel says why in plain words, and Fix it asks your model to repair it. You see the fixed version first, with Save and Undo.

  • Turn on Fix my mods automatically when a site changes and Morse fixes them for you, then tells you, with Undo.
  • Got the mod from the gallery? Share the fix, so everyone who uses it gets it too.

Your style

One look, on every site and app.

Say it once, ending with “everywhere”: Georgia font, bigger text and underline links everywhere except Figma. Every site and app you open has it from then on.

  • No model needed for the basics: font, text size, calmer colors, dark pages, no autoplay.
  • Not on this site leaves one site out.
  • Fit to each site: your model fixes what your style breaks on a site, and you review it like any change. Off until you turn it on.

Mod packs

Share a set of mods with your team.

A pack is a few mods with a name and a note, shared and installed together, as a link or a file. For a team that wants the same changes to the tools it uses every day.

  • Whoever installs it sees every mod and what it does, and unticks what they don’t want.
  • Nothing is installed until they press Install.
  • When the pack changes, Morse shows what changed before anything updates.

Desktop apps

Not just websites. Desktop apps too.

Many desktop apps are web pages inside a window. morse launch opens one with Morse connected: point, say the change, save it. Tried so far on Linux with VSCodium, Obsidian, Joplin and a sample app made for testing.

Privacy

Uses the AI you already have. Nothing goes to our servers.

There is no Morse account and no Morse server. When you ask for a change, Morse sends what you pointed at and what you said to the model you chose, and nothing to the people who make Morse.

  • Your model, your account

    Claude Code or Codex with the sign-in you already have, or an Anthropic or OpenAI API key.

  • Kept on your computer

    Your mods stay on your computer. Nothing you make is uploaded unless you share it.

  • Links carry the mod

    A share link holds the whole mod after the #. Browsers never send that part to a server.

  • You see the code

    Every change shows its code and can be undone. Before you install a shared mod, Morse says what it does.

The privacy policy lists everything that leaves your computer, and when.

Install

Set up in about a minute.

You need Node 22 or newer, and Claude Code, Codex or an API key.

Desktop apps

$ npm install -g morse-cli
$ morse setup

morse setup finds Claude Code, Codex or an API key and asks which to use. Then open an app with Morse:

$ morse launch obsidian

morse apps lists the apps it found on this computer. You can also give a path to the app.

Chrome

  1. Install the morse command, as for desktop apps. The extension comes with it: morse extension shows its folder.
  2. Open chrome://extensions, turn on Developer mode, click Load unpacked and choose that folder.
  3. In Morse’s details, turn on Allow User Scripts.
  4. Run morse serve and type its code into Morse. Or paste an Anthropic API key in Morse’s settings instead.

Then press ⌥ Space on any page. Morse is coming to the Chrome Web Store.

Morse is early: the status notes say exactly what has been tested.

FAQ

Questions people ask first

What is Morse?

Morse lets you change any website or desktop app by saying what you want. Press a shortcut, point at something and describe the change. Your model writes it and you see it right away. If you like it, save it as a mod: a change you saved. Morse brings it back every time you open that site or app.

What leaves my computer?

When you ask for a change, Morse sends your request, the page address and title, and the part of the page you pointed at to the model you chose. When you open Morse, it may download the gallery list from GitHub, at most once a day. Nothing goes to the people who make Morse. Read the privacy policy.

Which models can I use?

Claude Code or Codex, if you have them. Or an Anthropic or OpenAI API key. Or any server that works like OpenAI’s, including one on your own computer, such as LM Studio or llama.cpp. morse setup finds what you have. Claude Code is the one tried for real so far; the others are tested against stand-ins.

What does it cost?

Morse is free. Your model costs what it already costs you: Claude Code and Codex use your subscription, and with an API key, Anthropic or OpenAI bills you for each request. A change is usually one request, and one more if Morse has to fix it.

Which apps work?

Websites in Chrome: tried on sites such as PyPI, GitLab and Docker Hub. Desktop apps built from web pages: tried on VSCodium, Obsidian and Joplin, on Linux. Microsoft’s VS Code, Slack, Discord, Spotify, macOS and Windows aren’t tried yet. A few apps block the connection Morse needs; morse fuses <app> tells you before you try. Apps that are not built from web pages, like Finder or Word, don’t work.

Do I need to know how to code?

No. You describe the change in your own words. If you do code, you can read and edit every line Morse writes.

What if the app or site updates?

Morse never changes the app’s files, so updates install as usual. If an update moves things around, a mod can stop working. Fix it in the Mods panel asks your model to repair it, or Morse can fix it for you when you turn that on.

Is it safe to install mods other people made?

A mod is code that runs in that site or app. Before you install one, Morse tells you in plain words what it does and shows its code. Someone reads every gallery mod before it goes in. One shortcut turns off every mod on a page.
