Describe the hack. Watch the app change.

No waiting for a feature request. Open the app and tell Morse what to add or remove.

  1. Open Morse.

    Press ⌃⌥Space on Mac, or CtrlAltSpace on Windows and Linux.

  2. Tell it what to hack.

    “Delete YouTube Shorts.” “Add an export button.” “Build Gmail’s snooze here.” Type it or say it. Morse inspects the app, writes a mod and applies it while you watch.

  3. Keep your version.

    Hit Save to keep the mod. Keep hacking from there. Hit Undo whenever you want the original back.

    What can you actually hack?

    Can I steal my favorite feature from another app?

    Yes. Tell Morse which behavior to rebuild and where to put it. A command palette on a website. An export button in an app that left one out. Morse writes a mod for the app you have open; it doesn’t copy another service’s backend.

    Can I delete a paywall?

    If the article has loaded and a paywall overlay covers it, Morse can remove that overlay. Content kept on the publisher’s server still requires access; removing a box cannot retrieve it.

    Can I put my own AI inside an app?

    Yes. Add your own AI controls to the app you already use: a button that checks a thread for contradictions, or a panel that answers questions about the page. Morse works with Claude Code, Codex, or your API key.

    Does the source code have to be public?

    No. Morse reverse engineers the interface and code it can inspect in the running app, then writes your mod. The company doesn’t have to publish its source. The changes run on your computer; they don’t give you control of the company’s servers.

    What does it cost?

    Morse is free. Your model costs what it costs you now. A change is usually one request.

    Which apps work?

    Websites in your browser, and desktop apps built from web pages, like Visual Studio Code, Obsidian and Logseq. Apps like Finder or Word aren’t built from web pages, so they don’t work.

    What if the app updates?

    Updates install as usual. If one breaks a change, click Fix it and your model writes it again.

    Is it safe to install changes other people made?

    Before you install one, Morse says what it does and shows its code. One shortcut turns every change off.
