    Install

    Get Morse.

    Pick where you want to change things. You need Claude Code, Codex or an API key.

    Chrome

    Any website

    The Morse extension for Chrome.

    Add to Chrome→
    Not in the Chrome Web Store yet. Install it by hand
    1. Install the morse command (below). The extension comes with it: morse extension shows its folder.
    2. Open chrome://extensions, turn on Developer mode, click Load unpacked and choose that folder.
    3. In Morse’s details, turn on Allow User Scripts.
    4. Run morse serve and type its code into Morse, or paste an Anthropic API key in Morse’s settings.

    Desktop apps

    Apps like VS Code, Obsidian and Joplin

    Morse for desktop apps built from web pages.

    Download Morse→
    No download yet. Use the morse command
    1. Install it: npm i -g morse-cli (needs Node 22 or newer).
    2. Run morse setup. It finds Claude Code, Codex or an API key and asks which to use.
    3. Open an app with Morse: morse launch obsidian. morse apps lists the apps it found.

    For developers

    $ npm i -g morse-cli

    then morse setup

    Your first minute

    1. 1Morse opens a welcome page, with a practice page to try it on.

    2. 2morse setup finds Claude Code, Codex or an API key.

    3. 3Point, say a change, Save. Then try it on any site.

    Privacy

    Morse has no account and no server. When you ask for a change, it sends what you pointed at and what you said to the model you chose, and nothing to the people who make Morse. Read the privacy policy

    FAQ

    Common questions.

    More in the guides.

    What does it cost?

    Morse is free. Your model costs what it already costs you: Claude Code and Codex use your subscription, and with an API key, Anthropic or OpenAI bills you for each request. A change is usually one request.

    Which models can I use?

    Claude Code or Codex, if you have them. Or an Anthropic or OpenAI API key, or a model on your own computer, such as LM Studio or llama.cpp. Claude Code is the one tried for real so far.

    Which apps work?

    Websites in Chrome, and desktop apps built from web pages. Tried on Visual Studio Code, VSCodium, Obsidian, Logseq and Joplin, on Linux. Slack, Discord, Spotify, macOS and Windows aren’t tried yet. Apps like Finder or Word are not built from web pages and don’t work.

    Do I need to know how to code?

    No. You describe the change in your own words. If you do code, you can read and edit every line Morse writes.

    What if the app or site updates?

    Morse never changes the app’s files, so updates install as usual. If an update moves things around and a mod stops working, Fix it in the Mods panel asks your model for a new version.

    Is it safe to install mods other people made?

    A mod is code that runs in that site or app. Before you install one, Morse says in plain words what it does and shows its code. One shortcut turns off every mod on a page.
