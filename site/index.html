How it works

Point. Say it. Watch it change.

  1. ⌥Space
    01

    Point at anything

    Press ⌥ Space in any page or app and hover to highlight a button, a sidebar, a feed. Or skip pointing and describe a page-wide change.

  2. “hide Shorts”
    02

    Say what you want

    One sentence. Restyle it, hide it, or add something that wasn’t there: a word count, a sleep timer, a focus mode.

  3. 03

    Watch it change

    CSS applies while the model is still writing it. If the JavaScript throws, Morse shows the model the error and it fixes itself. Keep it, undo it, or edit the code.

Models

Bring your own model.

Morse has no backend and no account. It hands what you pointed at and what you said to the coding model you already use, and runs what comes back.

  • Claude Code Uses your existing Claude Code sign-in.
  • Codex Uses your existing Codex CLI sign-in.
  • An API key Any OpenAI-compatible endpoint, cloud or local: Ollama, llama.cpp, LM Studio, vLLM.

Where it works

Websites and desktop apps.

Most software you use every day is Chromium running JavaScript. Morse injects one small runtime into it, in the browser or in the app.

Any website

A Chrome extension. Mod JavaScript runs through chrome.userScripts, so it works on sites with a strict Content-Security-Policy too.

Electron desktop apps

morse launch spotify restarts the app with a local debugging port and attaches over CDP. App files are never patched, so code signatures stay intact and updates don’t break it.
