Get set up

  • Connect a model Morse uses an AI you already have: Claude Code, Codex or an API key. Paste this in a terminal and press Enter. morse setup Says “command not found”? Run it in the Morse folder as node daemon/cli.js setup.
    Use an Anthropic API key instead The key stays in this browser. Nothing to install.
  • Turn on “Allow User Scripts” Without it, changes to how a site looks still work, but new buttons and features don't run on some sites.
  • Make your first change On the practice page, or on any website. Save it, and it's there next time.
  • Pin Morse to the toolbar Click the puzzle piece next to the address bar, then the pin next to Morse. Its menu shows your mods and settings.

Good to know

Tabs that were already openReload them once. Chrome only adds Morse to pages loaded after it was installed.
Where Morse can't runChrome's own pages, the Chrome Web Store and PDFs in Chrome's viewer. Files on your computer need “Allow access to file URLs” in .
Help while you workIn the Morse bar, F1 shows what you can do and example sentences, and ? shows keyboard shortcuts.
Nothing is permanentA change you save is called a mod. Morse brings it back every time you open that site. opens the Mods panel, where you can turn one off, edit it or share it.
